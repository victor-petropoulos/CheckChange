# Competitive Context

Research found substantial existing capability in SonarQube, Codacy, CodeScene, Qodana, MegaLinter, language-specific CRAP tools, static/security analyzers, and coverage systems.

This project should not compete with them.

The remaining possible niche is deliberately modest: free, local-first, small, no account/cloud/LLM/platform adoption, compose tools already present, focus on the current change, and return a simple deterministic result.

"Free code analysis," "change-oriented quality gates," and "complexity plus coverage" are not novel.

Do not manufacture differentiation. If an existing free/simple tool makes this unnecessary, document that and stop.
