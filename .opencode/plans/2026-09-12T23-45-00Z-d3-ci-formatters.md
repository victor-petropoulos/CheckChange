# D3 CI/PR Formatters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add three pure CI/PR formatters (GitHub Annotations, JUnit XML, SARIF 2.1.0) as new files under `src/formatters/` with an additive `--format` CLI flag in `src/cli.ts`. Zero changes to existing emitters, gate/completeness logic, or schema version.

**Architecture:** Pure sidecar functions `(EvidenceOutputShape, {cwd}) => string` that consume the existing `buildEvidenceOutput` return value already cached in `runCheck`. Formatters never call engine code. CLI wiring adds `--format` validation and a conditional emit branch that preserves byte-identical `--json`/human output when `--format` is absent.

**Tech Stack:** TypeScript, Node.js built-ins only (no new deps). Vitest for unit/integration tests. Output verification via deterministic JSON/XML string comparison.

- Produces: Three pure functions:
  - `formatGitHub(out: EvidenceOutputShape, opts: {cwd: string}): string`
  - `formatJUnit(out: EvidenceOutputShape, opts: {cwd: string}): string`
  - `formatSARIF(out: EvidenceOutputShape, opts: {cwd: string}): string`
  - `format(out, fmt, opts)` dispatcher in `index.ts`

**Implementation details per researcher recon:**

**github.ts** — Iterate `out.ruleResults` where `result === 'WARN'` or `'NOT_EVALUATED'`. Emit `::warning file={file},line={lineStart},endLine={lineEnd},title=high CRAP:: {method} CRAP {crap} > {threshold} (cc {cc}, cov {coverage})` using relative `file` verbatim. Also produce PR-comment markdown table over `changedFunctions` + `ruleResults` + `gate`/`completeness` (return both as `\n\n---\n\n` separated string or object; `index.ts` decides what CLI emits).

**junit.ts** — Build JUnit XML: `<testsuite name="checkchange" tests="{changedFunctions.length}" failures="{warnCount}">` with per-function `<testcase classname="{file}" name="{method}" file="{file}" line="{lineStart}">`. `PASS` → no child; `WARN` → `<failure message="CRAP {crap} > {threshold}">...</failure>`; `NOT_EVALUATED` → `<skipped/>`. Escape XML entities (`&`, `<`, `>`, `"`, `'`).

**sarif.ts** — Build SARIF 2.1.0: `{version:"2.1.0", runs:[{tool:{driver:{name:"checkchange",version:out.schemaVersion, rules:[{id:"changed-function-high-crap"}]}}, results: warnResults.map(r => ({ruleId, level:"warning", locations:[{physicalLocation:{artifactLocation:{uri:r.file}, region:{startLine:r.lineStart, endLine:r.lineEnd}}}], message:{text:`${r.method} CRAP ${r.crap} > ${r.threshold} (cc ${r.cc}, cov ${r.coverage})`}})}]}`.
