# WP5 Complete Planning Package

This package plans all of WP5 in advance. Later work packages contain
dependency gates because their details must be reconciled with findings
from earlier work.

## Repository location

Place these files under `experiments/wp5/planning/`.

## Execution order

1.  WP5.1 prompt → human approval
2.  WP5.2 prompt → human approval
3.  WP5.3 prompt → human approval
4.  WP5.4 prompt → human approval
5.  WP5 Final prompt → closure review

Do not give OpenCode all prompts as one autonomous chain. Every stage
has a stop gate.
