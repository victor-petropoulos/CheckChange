# WP5 Traceability — WP5.4 Preparation

Create/update the active matrix only after taxonomy reconciliation.

For each authorized finding record:

- authoritative FM ID;
- original WP5.2 evidence;
- WP5.3 disposition if applicable;
- WP5.4 characterization;
- invariant;
- code location;
- regression test;
- before/after behavior;
- final disposition.

Do not mark any finding resolved without executable after-fix evidence.

## Deferred by design

WP5.4 must not reopen:
- WP5.3 source attribution;
- WP5.3 source discovery;
- WP4R CRAP arithmetic;
- thresholds;
- coverage provider implementation;
- language expansion.
